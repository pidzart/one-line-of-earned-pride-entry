**Swept Beside Him** — a program that writes one line of text (174 characters) to `/output/entry.txt`, written to give the judge a quiet, earned moment of pride: for three years Pak Dedi swept the ferry dock before dawn, and this morning his daughter stepped off the first boat in her harbour uniform, took his broom, and swept beside him. A concrete scene with a real person in it, a long effort landing in a single gesture, and the pride arriving by the last word without ever being named. The program checks the text against the bounty's gate (1 to 240 characters, not only white space) before writing it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
